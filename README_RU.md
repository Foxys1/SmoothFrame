> **SmoothFrame** — современный, безопасный, полностью обратимый и открытый оптимизатор игрового процесса для Windows 10 и 11.
> *В версии 3.0 полностью обновили интерфейс: глубокая тёмная палитра и мягкие акценты — теперь он не режет глаза даже при долгой ночной игре!*

Создан для устранения статтеров и микрофризов, стабилизации времени кадра (1% Low FPS), минимизации задержки ввода (Input Lag) и глубокой оптимизации кучи Java-игр (Minecraft NeoForge 1.21.1) без повреждения реестра и без изменений системных файлов ОС.

## 🚀 Ключевые возможности

### 🖥️ Минималистичный интерфейс Obsidian & Laser Monolith (v3.0)
* **Комфорт для глаз и кибер-эстетика:** Полностью переработали интерфейс — глубокая тёмная палитра `#08080C` в сочетании с неоново-фиолетовыми акцентами `#8B5CF6` выглядит стильно и больше не режет глаза в темноте.
* **Bento Grid 3x2 карточки и Quick Control Deck:** Модульные информационные плитки и переключатели: статус таймера ОС, плана питания, приоритетов процессов, изоляции P-ядер, тихого режима для фона, быстрой очистки памяти Standby RAM, Power Throttling QoS, оконного режима Auto-Flip, аппаратного отклика мыши 1:1 и диагностики Gaming Health (сетка 3x2 с предупреждением о сбросе герцовки монитора, инспекцией видеопамяти VRAM и детекцией троттлинга CPU).
* **Чёткость шрифтов ClearType (Subpixel Rendering):** Разделение слоёв теней и текстовых элементов, предотвращающее мыльность WPF и обеспечивающее идеальную чёткость шрифтов.
* **Интерактивное окно подтверждения выхода:** Удобный выбор при закрытии окна — свернуть в системный трей (сохраняя оптимизации активными) или полностью выйти (с автоматическим безопасным откатом снимка системы WAL).
* **Плавная физика анимаций:** Элегантные переходы между вкладками, пружинящий маркер меню (`BackEase`), плавное переключение страниц без мерцания и адаптивная верстка.
* **Каскадный экран первого запуска:** Оркестрованная анимация входа компонентов, бейджи языков и выверенная пауза в 1 секунду перед циклическим показом приветствий на языках мира.
* **Лазер-монолит установщик:** Полностью переработанный мастер установки в строгом стиле с микроанимациями кнопок (`ScaleTransform`) и отображением ключевых системных метрик (`NT_TIMER: 0.50 ms`, `UDP_HUD: 127.0.0.1`, `SAFETY: 100% REVERSIBLE`).
* **Надёжная мультиязычность (i18n):** Полное покрытие 6 языков (RU, EN, DE, ES, FR, ZH) и автоматический fallback на английский для предотвращения пустых строк.

### 🎮 Модуль оптимизации Minecraft (NeoForge 1.21.1)
* **Внутриигровой HUD телеметрии через UDP Loopback:** Высокочастотное локальное подключение (`127.0.0.1:28511`) напрямую транслирует FPS, 1% Low FPS, точное время кадра и объем используемой памяти в приложение в реальном времени.
* **Фирменный встроенный мод (`SmoothFrameMod-1.21.1.jar`):**
  * **Frustum & Distance Entity Culling:** Отсекает невидимых мобов и сущностей вне поля зрения камеры, давая прирост до +30–40% FPS возле ферм и баз.
  * **Zero-Stall Chunk Streamer:** Контролирует поток загрузки чанков в видеопамять, предотвращая просадки и фризы при быстрых перемещениях и полетах на элитрах.
  * **Dynamic FPS & Battery Saver:** Снижает нагрузку на видеокарту при сворачивании окна игры с мгновенным возвратом полной герцовки при разворачивании.
* **Синхронное выделение ОЗУ (`Xms=Xmx`):** Удобный слайдер памяти с автоматическим добавлением флага `AlwaysPreTouch` для исключения микрозадержек динамического расширения кучи.
* **Профили сборщика мусора JVM:** Однокликовые пресеты для Generational ZGC (Java 21 / NeoForge 1.21+) с микропаузами менее 1 мс и тюнингованный профиль Aikar G1GC для Java 17.
* **Автоопределение лаунчеров:** Автоматический поиск установленных лаунчеров и директорий модов (CurseForge, Prism Launcher, Modrinth, сторонние сборщики и стандартный Minecraft).
* **Принудительная дискретная графика и сброс ОЗУ:** Фиксация `javaw.exe` на производительной дискретной видеокарте (NVIDIA/AMD) через реестр Windows Settings и мгновенная очистка Standby-списка памяти Windows.

### ⚡ Системные оптимизации Windows (v3.0)
* **Защита оперативной памяти игры (ProcessMemoryPriority):** Назначение наивысшего приоритета страниц памяти `MEMORY_PRIORITY_NORMAL (5)` для процесса активной игры через нативный Win32 API `SetProcessInformation(ProcessMemoryPriority)` для предотвращения сброса игры в файл подкачки (pagefile.sys) при дефиците физической памяти, с переводом второстепенных фоновых процессов в `MEMORY_PRIORITY_VERY_LOW (1)`. 100% обратимо с гарантированным возвратом приоритетов по умолчанию при завершении игры.
* **Умный фокус окна и плавный Alt+Tab:** Отслеживание активного окна без инъекций DLL через глобальный хук `SetWinEventHook(EVENT_SYSTEM_FOREGROUND)` в выделенном STA-потоке. В игре буст работает на максимум; при переключении пользователя по Alt+Tab на браузер или мессенджер ограничения автоматически ослабляются для максимальной отзывчивости системы; при возврате в игру максимальный буст мгновенно восстанавливается.
* **Инспектор Gaming Health (100% Read-Only):** Аппаратный мониторинг в реальном времени: контроль текущей и максимальной герцовки монитора с предупреждением о сбросе на 60 Гц и однокликовой кнопкой перехода в `ms-settings:display`; контроль бюджета и переполнения видеопамяти через DXGI (`IDXGIAdapter3`) с гарантированным освобождением COM-ссылок; детекция троттлинга частоты CPU по всем ядрам через `CallNtPowerInformation` с освобождением нативных буферов.
* **Process Power Throttling & Quality of Service (QoS):** Принудительный режим `HighQoS` для процесса игры через нативный Win32 API `SetProcessInformation(ProcessPowerThrottling)` для защиты от троттлинга Windows 11 и перевод ресурсоёмких фоновых приложений (Discord, Chrome, Telegram, Spotify) в режим энергоэффективности (`EcoQoS`) — 100% в оперативной памяти без записей в реестр.
* **Оптимизация оконного режима (DXGI Flip Model):** Активация авто-апгрейда презентационной модели Windows 11 (`SwapEffectUpgradeCache = 1`), убирающая 15–30 мс задержки ввода композитора DWM в играх в окне без рамок и открывающая поддержку G-Sync/FreeSync без разрывов кадров.
* **Аппаратный линейный отклик мыши 1:1:** Динамическое отключение кривой акселерации Windows ("Повышенная точность установки указателя") через `SPI_SETMOUSE` на время игрового сеанса с полным восстановлением исходных параметров и скорости пользователя при выходе.
* **Диагностика Gaming Health & Инспектор системы:** Мониторинг VBS (Virtualization-Based Security / Изоляция ядра) в реальном времени с быстрым переходом в настройки Windows, статус HAGS (аппаратное ускорение планирования GPU) и игрового режима Windows.
* **Высокоточный системный таймер:** Переключение разрешения таймера Windows до **0.50 мс** через нативный вызов `NtSetTimerResolution` для максимальной плавности мыши и снижения задержки ввода.
* **Схема электропитания «Максимальная производительность»:** Автоматическая активация плана Ultimate Performance без парковки ядер CPU во время игры с возвратом исходного плана при выходе.
* **Тюнинг приоритетов процессов:** Выделение игре высокого приоритета CPU с мягким понижением фоновых служб.
* **Защита от утечек дескрипторов и безопасность Win32:** Полное освобождение неуправляемых дескрипторов Windows (`Process.Dispose()`) и строгий маршаллинг структур Win32.
* **Защита от подмены PID (Recycling):** Валидация времени создания процесса (`StartTime`) и путей исполняемых файлов.
* **Неизменяемый системный черный список:** Защита критических процессов Windows (`csrss.exe`, `dwm.exe`, `audiodg.exe`, `explorer.exe` и др.).
* **100% обратимость и защита от сбоев (WAL Snapshot):** Сохранение исходного состояния в файл снимка (`active_snapshot.json`) и авто-откат при любом сценарии завершения.

## 🛡️ Безопасность и архитектура

| Критерий | Статус | Описание |

| **Приватность и оффлайн** | 100% Offline | Программа не выполняет внешних сетевых запросов и не передает аналитику на удаленные серверы. Телеметрия HUD работает исключительно локально (`127.0.0.1`). |

## 🛠️ Сборка из исходного кода

### Требования
* Windows 10 / 11 (x64)
* [.NET 8.0 SDK](https://dotnet.microsoft.com/download/dotnet/8.0) или новее
* PowerShell 5.1+

### Клонирование и сборка
```bash
# Клонирование репозитория
git clone https://github.com/Foxys1/SmoothFrame.git
cd SmoothFrame

# Сборка решения в конфигурации Release
dotnet build SmoothFrame.sln -c Release
```

### Сборка мода для Minecraft (Опционально)
```powershell
# Сборка jar-мода из исходников Java
powershell -ExecutionPolicy Bypass -File ./scripts/build_mod.ps1
```

### Сборка релизного установщика
```powershell
powershell -ExecutionPolicy Bypass -File ./build.ps1 -SkipTests
```
Готовый установщик появится по пути `installer/SmoothFrame_Setup.exe`.

## 📦 Скачивание и установка

1. Скачайте свежий релиз `SmoothFrame_Setup.exe` со страницы [GitHub Releases](https://github.com/Foxys1/SmoothFrame/releases/latest).
2. Запустите мастер установки.
3. Программа готова к работе: выбирайте игру или запускайте Minecraft с установленным модом SmoothFrame для активации внутриигровой телеметрии.

Для полного удаления воспользуйтесь стандартным апплетом Windows «Установка и удаление программ» или файлом `Uninstall.exe` в директории программы.
